# 首页排版与动效

首页延续落樱小筑的纸白、樱粉与夜色配色，保留现有顶部风景、正文宽度和底部渐变。

- 首页四个项目统一采用 2×2 网格，按 ORULINK、TaskHub、ClothHub、学绩的顺序排列。同一行卡片对齐，行高由项目内容决定，统一呈现封面、标题、分类、简介与底部技术标签。卡片圆角 26px，内嵌插画圆角 18px，技术标签采用胶囊形。
- 桌面侧栏宽度为 348px，1101–1180px 屏幕下为 320px。介绍卡精简重复简介，把统计改为横向数字与说明，提供关于页入口；日历保留独立的日期操作和手记入口。
- “走进作品集”位于整个项目区域底部的右侧，与“更多手记”对齐。统计数字采用等宽数字，与说明横向对齐；手记标题加重，日期和分类分别呈现。
- 拾日历按周一开始，使用上海时区标记今天。区分今天、选中日期和有文章的日期；支持月份切换、回到今天及当天文章直达。日期区固定六周，文章预览区固定为 128px，最多显示两篇单行标题，完整标题保留在链接名称及悬停提示中；通过独立入口前往按当天日期筛选的手记列表。文章数量和月份不会把卡片撑高。日期区只有一个 Tab 停靠点，方向键、Home/End、PageUp/PageDown 可切换日期。
- 项目区与侧栏各自按内容排版，取消共享行高和介绍卡填充拉伸，不为对称扩张卡片。四张封面统一使用 2.1:1 比例，技术标签靠底对齐。分类筛选仅保留两个项目时，桌面切为上下两张横向卡片；侧栏尺寸不受筛选结果影响。
- 最新手记在桌面使用左侧一张主推、右侧两张图文卡的杂志式排版，统一圆角、图片内边距、日期分类和阅读时长。760px 以下切为单列，主推保留大图，另两篇采用紧凑图文卡。
- 1100px 以下侧栏移至项目下方并排顶对齐，各自保持自然高度；760px 以下项目为单列；600px 以下侧栏为单列。首页布局统一由 `home.css` 管理，`scene-framing.css` 不再重复覆盖首页卡片规则。
- 首页单独设置明暗主题的说明文字、强调色和装饰文字颜色；日期、标签、统计说明等辅助信息为 12–13px。日历相邻月份使用独立文字色，避免低透明度造成难以辨认，封面编号增加深色底以适应不同插画。
- 首页标题采用明确字重层级：栏目与卡片标题为 700，入口与标签为 600–650，正文为 500。手记标题改用黑体，正文统一为 14px，日历说明与侧栏入口为 13px；栏目标题和个人卡名称保留宋体。窄屏统计标签保持完整一行，“更多手记”与标题说明分配独立列。

## 动效

`WindPetals.astro` 是顶部和底部共用的花瓣组件。首页顶部 112 片，其他顶部 72–80 片，底部 76 片；手机最多显示顶部 60 片、底部 44 片。

花瓣包含三层景深、五种轮廓与五种色调。晨曦偏粉、桃、奶白，晴昼加入柔和嫩绿，黄昏偏暖杏与藕紫，月夜偏珍珠、灰紫与冷蓝。配色跟随各自风景区域的时段，手动切换场景时同步更新。

`petal-physics.ts` 使用像素空间的视觉物理模型：重力与二次空气阻力控制下落，速度逐渐接近终端速度；缓慢变化的侧风、局部摆动与角速度阻尼控制横移和翻转。每次飞行按 60Hz 积分，采样后交给浏览器的 transform/opacity 动画播放，不在每帧运行页面脚本。不同花瓣的尺寸、景深、起点和翻转参数独立变化，始终向下飘落，每轮在可见区域之外重新开始。花瓣只出现在风景中，不穿过正文。

这是为观感设计的近似模型，力学关系参考 [NASA 的重力与空气阻力说明](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/falling-object-with-air-resistance/)，不用于真实花瓣的气动预测。

`interaction-motion.ts` 负责标题错落入场、筛选反馈、日历说明更新和卡片鼠标反光/封面轻移；`atmosphere.ts` 负责滚动入场及可见性。文本始终有可读的静态状态，连续动效主要使用 transform 和 opacity。

现有扇形菜单的暂停开关统一控制这些动效，切页后保留选择。系统减少动态效果时不显示花瓣，也不播放入场或悬停位移。画面离屏、窗口隐藏或页面切换后，相关动画、观察器及待执行的帧会暂停或清理。
