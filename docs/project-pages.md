## 内容与阅读顺序

- 列表页标题为「从想法，到作品。」，使用本地马善政手写字形，放在独立樱窗动景上。介绍、英文与导航延续首页的排版；分类筛选由真实分类生成。
- 四张卡片采用统一纸面底色与细边框；封面内收 10px（手机 8px），内外圆角依次收小。标题、说明与底部技术信息对齐，技术栈以分隔点串联并由细线分区。手机单列，桌面和平板两列。
- 详情使用统一展示框架，功能区域支持点击、方向键和首尾键切换；图片支持大图、原尺寸、Escape 关闭与焦点返回。
- 模块概览按职责展示，不将模块列表画成未经验证的运行调用流程。技术说明保留源码归纳与分析性判断的区分。
- 首页和列表保留主题封面；详情按来源区分本地运行、虚构样例与产品设计参考。保留各项目的功能与实现边界，不新增未经核实的业务结果。
- 结尾提供返回作品集与下一项目，保留原有项目顺序。

## 页脚与场景

项目列表与详情采用樱窗书桌顶部与花溪小桥底部，各有晨曦、晴昼、落日、月夜四个时段。旧切换栏和暂停按钮改为可拖动樱花轮盘：先选顶部或底部，再选时段。两处偏好分别保存，支持刷新、跨页面和跨标签页同步，默认跟随本机时间。列表已删除额外说明段落，详情保留主题插画标识。

透明导航直接复用首页 Header。列表顶部桌面 460px（大屏 500px）、手机 385px；详情缩为桌面 320px、手机 260px，避免重复的大图占用阅读空间。详情横幅标题使用段落，项目名称仍是页面唯一 h1。

八段本地 24 秒 MP4 循环让枝叶、云层与水面轻动，保留主题色渐隐、离屏停止和系统减少动效。页脚为桌面 350–450px、手机 380px 的紧凑横幅，靠右下裁切多余天空，保留桥身与溪流；水域叠加细碎反光与扩散涟漪，落款保持清晰。项目寄语为：「每个作品，都是成长的注脚。／下一段故事，正在慢慢发生。」素材、完整提示词与制作方式见 [项目四时动景](./project-scene-times.md)。

文案在 `src/data/page-copy.json` 中维护。改动后按需执行：

```sh
node scripts/update-fonts.mjs --projects-only
node scripts/update-fonts.mjs --footer-only
node scripts/update-fonts.mjs --body-only
```

字体为本地 OFL 开源子集，页面不请求远程字体。深浅主题使用全站语义色，系统减少动效由现有播放器处理。字体更新若收到多个分片，会停止并保留现有文件，避免写入不完整字形。
