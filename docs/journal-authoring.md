# 手记与知识：内容组织

## 2026-10-20 内容整理

内容按四类组织，每类一篇完整主文与一篇专题补充，共八篇，保留既有链接。主文分别完整介绍手记站从零搭建、Python 索引工具实战、Coding Agent 系统结构，以及需求到验收的交付方法；补充篇聚焦 UI 选型、运行时校验、概念对照和技术写作。Python 主文提供完整源码、示例数据、八个测试与下载包，所有长文都有章节导航和原始出处。

文章在正文相关位置引用原始资料，末尾集中列出来源及域名。公开文章的观点经过归纳，教学代码、本站源码事实和工程建议分别说明，不虚构性能数据、排行榜对比或亲历结果。发布后变更资料时，应更新日期并重新核对结论。

归档开篇显示内容定位与实际篇数，卡片显示细分主题、阅读时间和参考数量。侧栏保留日历和主题索引，已移除“按线索阅读”。归档每页三篇，提供页码、上一页、下一页和跳页；页码保存在 URL 的 page 参数中，筛选与排序变化后回到第一页，进入文章再返回时保留条件与页码。手机先展示筛选、文章与分页，日历和标签放在列表后，避免查找工具挡住内容。文章保留整列阅读，正文宽度上限为 880px，新增可折叠的正文导航，工具栏目录仍支持二级与三级标题。

检索仍针对标题、简介、分类与标签，未宣称支持正文全文搜索。阅读时间是编辑估计，不是精确计时。

手记列表位于 `/blog/`，首页的最新手记仍使用原来的简洁图文样式。列表按类型、关键词、单日或起止日期查找，筛选结果可直接复制网址分享。日历与主题区使用细边框、20px 圆角的独立外壳。完整月历以周一为一周开始，每个日期下显示符合当前分类和关键词的实际篇数。点击日期或主题后在原位置更新结果，不强制滚动或移动焦点到列表；空日期显示空状态。点击月份标题切换年月；快捷入口包括今天、本周（周一至周日）、本月和最近记录。

“自定义日期”打开独立的日期弹窗，桌面对照两个月，手机显示单月。依次选择开始、结束日期，也可使用今天、本周、本月、近 30 天快捷填入；点击年月标题可跳转月份，再点击年份可选择年份。跨月、跨年与反向选择均包含起止两天。弹窗中的选择是草稿，点击“应用日期”后才查询，取消、Escape 或点击遮罩不会修改当前筛选。“清除日期”只清除日期条件，保留关键词和分类。首页日历的日期入口继续有效。主题标签使用统一颜色样式，侧栏标签可点击检索或再次点击取消。

分类栏使用加粗文字与独立数量标记。搜索与自定义排序合并在一条工具栏中，下方直接展示文章卡片，不重复显示分类标题。动态结果篇数位于列表右下角，并作为完整短句向辅助技术播报。文章卡片与侧栏采用 20px 圆角，图片 12px，搜索与排序工具 16px，分页控件 12px；通过层级保持一致。分页先在全部匹配结果上排序与切分，统计仍基于完整匹配集合；当前属于客户端展示分页，并非网络按页加载。无 JavaScript 时展示全部文章并隐藏增强控件。

## 四种类型

| type | 列表名称 | 内页重点 | 建议的正文结构 |
| --- | --- | --- | --- |
| `project` | 项目复盘 | 重点结论、主题图、关联项目、编号章节 | 背景 → 方案与取舍 → 实现 → 验证与边界 → 下一步 |
| `learning` | 学习笔记 | 学习要点、步骤、代码与复制工具 | 要解决的问题 → 概念 → 最小示例 → 实践 → 易错点 |
| `knowledge` | 知识归档 | 快速查阅、概念定义、表格、资料与出处 | 适用场景 → 核心概念 → 对照表或方法 → 边界 → 出处 |
| `essay` | 随想心得 | 安静的配图、舒展的段落、简化的章节 | 自由写作，使用二级标题组织长文即可 |

`category` 是更细的主题，例如“前端学习”“技术写作”“生活碎片”；`tags` 是跨类型的检索线索。旧文章没有 `type` 时会根据 category 推断，无法归类时按随想呈现。

## 写一篇记录

1. 从 `docs/journal-templates/` 复制合适的模板到 `src/content/blog/`，文件名使用简短英文短横线，文件名就是文章链接的一部分。
2. 修改标题、简介、日期、分类和标签，再填写真实的正文。模板的提示需要替换或删除。
3. `summary` 写 2–4 条正文已经解释过的要点；不是每篇都必须填写，最多 6 条。
4. 补充 `readingTime`（分钟）。后续修改内容时按需填写 `updatedDate`，内页会显示更新时间。
5. 本地确认目录、代码、表格和手机排版后，将 `draft` 改成 `false`。模板默认是草稿，不会进入页面、统计、搜索或 RSS。

可选字段：

- `relatedProject`：`orulink`、`taskhub` 或 `clotheshub`，在正文后的关联项目卡片连接现有项目。
- `resources`：由 `title` 和 `url` 组成的列表，放原始文档、出处或进一步阅读。链接使用 https/http 或站内路径。
- `coverCaption`：封面说明。项目和随想默认显示封面；学习与知识类默认优先显示内容，填写此字段才显示封面。
- `cover`：文章自己的图片地址，手记列表与文章头图使用同一来源，不再按文章文件名覆盖图片。封面只是主题图时，请在说明中明确表达，不当作真实运行截图。

## 正文能力

文章详情使用普通导航与图文开篇，不重复模块风景介绍。文章主标题、章节标题使用与正文协调的清晰无衬线字体，分别按 600、650 字重组织层级；简介、作者日期和主题标签分层排列。正文是独立的宽阅读区；二级和三级标题进入阅读工具栏的目录，默认关闭，按需展开，点击后定位并收起，不挤占正文宽度。工具栏显示当前章节、正文阅读进度与实际像素字号，A− / A+ 支持 16–24px 调节，默认 19px，偏好会记忆。字号同时作用于段落、引用、列表以及相应比例的代码、表格。外层手记列表保留随时间变化的风景页脚与场景菜单。文章详情不再重复显示作者结束栏或全站文字页脚；末尾统一在“接着翻一页”中提供相关文章、“回到篇首”和“全部记录”，后者保留进入文章前的筛选条件。

支持 Markdown 段落、列表、引用、代码、表格、图片、链接和脚注。代码注明语言后会高亮，浏览器支持时可以复制；宽代码和宽表格在各自区域内滚动，不会撑宽整页。原生 `<details>` 与 `<dl>` 可用于补充说明和术语定义。

没有 JavaScript 时正文、代码、表格、目录锚点和文章链接仍可阅读。搜索和交互筛选属于渐进增强。亮暗主题、花瓣与暂停偏好沿用全站设置。
