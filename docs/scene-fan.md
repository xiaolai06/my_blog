# 场景扇形菜单

樱花按钮展开一级扇面：顶部场景、底部场景、沉浸体验。选择分类后，在外侧展开该分类的第二层，一级入口保留，可直接切换分类。场景选项选中后保持菜单打开，方便对比。

- 顶部与底部的选择分别保存，时段选项来自 `scene-catalog.ts`，不会展示页面不支持的场景。
- 音乐空间记住进入前的本地页面，提供返回入口；暂停背景动效会保存到本地。
- 点击空白处或移出键盘焦点可关闭；Esc 先退回一级，再关闭。方向键在当前层移动焦点，Home/End 跳到首尾。
- 拖动樱花可调整位置，位置按视口比例保存。Alt + 方向键也可移动；Alt + Home 或“位置归位”恢复默认位置。

## 实现

`SceneDock.astro` 提供结构，`scene-dock.ts` 管理状态、位置及动效，`scene-dock.css` 管理主题和选中状态。

每个选项使用相同的 SVG 圆环扇面路径和 CSS `clip-path`，绘制区域与点击区域一致。标签保持正向，按极坐标布局，并检查图标、文字及角标各自的边界，避免在镜像方向裁字。菜单根据按钮所在象限选择展开方向；必要时临时移动锚点以避开屏幕边缘，关闭后回到保存位置。

主图标为 26px，名称为 14px，增加图标与文字之间的留白，并扩大两层扇面的可用空间。受限于窄屏或短屏时，使用 24px 图标和 13px 名称，隐藏一级菜单的次要状态小字；状态仍可从第二层的选中项确认。布局直接测量文字、图标及角标的实际尺寸，字号调整后会重新计算安全位置。

使用 [`motion/mini`](https://motion.dev/docs/quick-start) 操作原生 DOM，不引入 React。展开只动画 `transform` 与 `opacity`，用短暂错峰区分层级；切换先停止旧动画，并用版本标记避免旧回调隐藏新菜单。减少动态效果偏好下仅做短淡入淡出，键盘操作直接完成展开，避免焦点等待动画。

参考：[Motion animate](https://motion.dev/docs/animate)、[Astro 组件](https://docs.astro.build/en/basics/astro-components/)。

## 验证

真实浏览器已检查 320、390、844（横屏）、1440 像素视口，在四角及中间位置展开各分类，逐项检查文字未被扇面裁切、实际点击命中正确选项。还检查了场景独立选择、拖动及位置保存、键盘返回、快速开合与切换、空白处关闭、音乐页面返回、背景动效开关、减少动态效果及深浅主题。项目静态构建通过。
