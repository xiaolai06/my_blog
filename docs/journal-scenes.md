# 手记场景

手记归档 `/blog/` 与文章详情共用独立的 `journal` 场景族。顶部为窗边手记，底部为沿河书舍。导航、首屏高度、手写标题、页面宽度和底部图片几何复用项目页；详情页使用紧凑首屏。

## 图片与文案

- 图片：`public/images/journal-{desk|river}-{dawn|day|dusk|night}.webp`，每张 2172 × 724，八张合计约 2.8 MB。
- 标题与底部寄语：`src/data/page-copy.json`。
- 首屏：`src/components/JournalHero.astro`。
- 独立样式：`src/styles/journal-scenes.css`。
- 底部继续使用 `Footer.astro`，通过 `variant="journal"` 选择图片和寄语。

图片使用内置 Image Gen 生成。两张白天原图确定构图，再分别生成清晨、黄昏和夜晚的光照变体，最后压缩为 WebP。核心提示词：

1. **窗边手记**：3:1 全幅全景，日式动画水彩风格；窗边木桌、摊开的手记与钢笔、茶杯、书架，窗外河道、柳树与樱花。左侧书架保留暗部以承载白色标题，右侧窗景展开；无人物、文字、电脑、界面和水印。
2. **沿河书舍**：3:1 全幅全景，同一水彩风格；右侧临河木质书舍、露台与长椅，柳树、樱花，左侧远山、石桥与低细节天空，河面倒影；无人物、文字、界面和水印。
3. **时段变体**：保留镜头、物件、建筑和树木位置，仅改变光照。晨曦使用淡粉晨光、蓝紫河雾；晴昼使用自然蓝天与柔和绿意；落日使用杏金光线、粉紫天空和初亮窗灯；月夜使用靛蓝月光、星空和暖色书舍灯火。页脚左上保留淡色薄雾，便于寄语阅读。

## 时间与交互

复用现有 `scene-clock`、`scene-preference` 与樱花场景菜单：05:00–09:00 晨曦，09:00–16:00 晴昼，16:00–19:00 落日，其余为月夜。自动跟随访客本机时间；顶部与底部可以分别预览，沿用原有偏好有效期。

`ImageScene.astro` 在首屏脚本中读取本机时间和已保存的偏好；`image-scene.ts` 负责图片解码与交叉淡入。下一幅图片成功解码后才替换旧图，连续选择最终收敛到最后一次请求，加载失败保留当前画面。系统减少动态效果时跳过过渡。关闭 JavaScript 时仍显示默认黄昏插画、文章列表和导航。

场景清晰度与阅读深浅主题分别控制，夜景也可以配合浅色阅读主题使用。顶部标题和底部寄语已补入本地手写字体子集。
