# 音乐模式

入口在樱花悬浮菜单的「沉浸体验 → 音乐空间」。`/music/` 不渲染博客导航、首页文字、推荐列表和页脚；右上角退出按钮返回进入前的博客路径，音乐继续播放。

## 视觉与场景

全屏复用现有 `hero-sunset-v4.mp4` / `hero-night-v4.mp4` 动态场景、静图回退与双视频叠化机制，沿用顶部场景的时间偏好。视频静音循环，背景控制与音乐音频相互独立。系统减少动态偏好、后台标签页和用户暂停均沿用场景播放器规则。

右侧单块半透明深色播放器：暖白文字、浅桃色主播放按钮、高光细边框、14px 背景模糊、23px 圆角。外观菜单可以调节通透度。桌面宽度约为视口的 26%，最多 438px；手机使用不超过 340px 的窄面板。背景没有额外的颜色蒙层。

播放器展开时可以拖动顶部「音乐空间」，收起后通过右上角「音乐」恢复。计时卡片可拖动标题或倒计时数字，在准备、进行、暂停和完成状态均可移动；点击计时数字则打开设置，拖动结束不会误开设置。两个卡片分别保存位置，支持鼠标、触屏、方向键微调、Shift 加方向键大步移动和 Home 归位；卡片菜单与设置中也有位置归位入口。位置按视口比例保存在当前浏览器，窗口变动时限制在可见范围内，隐藏时不重新计算为零尺寸。增加至 76 片前后景花瓣，使用不同大小、速度、翻转与虚化，沿弯曲轨迹持续飘落；减少动态偏好和暂停控制同样作用于花瓣。

`MusicPlayer.astro` 同时挂载在普通博客布局与音乐模式中，通过 Astro `ClientRouter` 和 `transition:persist` 保留同一个播放器与音频节点。退出后不再显示独立播放条，使用原有樱花悬浮菜单的「沉浸体验」暂停、继续、切歌或返回音乐空间；播放时樱花周围出现音符、细小波动和呼吸圆环，暂停时停止；站内换页不会重新开始歌曲。浏览器刷新、关闭标签页、站外导航不属于此连续播放范围，重新载入后等待用户手动恢复。

设计概念使用内置 Image Gen，根据用户附图生成；实际背景保留用户工程的原有动态视频。概念里的静态绘画和播放中的视频帧会有所不同。播放器保留现有樱花悬浮菜单，方便切换壁纸或退出音乐模式。

## 音乐与歌词

需申请 Client ID 的扩展方案与 GitHub 参考项目见 [免费音乐资源与 Jamendo 接入准备](music-sources.md)。该服务尚未接入，当前音源不需要 Key。

- 「免费精选」直接提供 6 首 Scott Buckley 官方发布的完整音乐：In This Moment、Home Was You、With These Hands、Wildflowers、Echoes Of Home、Penumbra。均为 CC BY 4.0，曲目页和播放器保留作者、原始标题、来源与授权链接；无需账号或接口密钥。音频按用户选择从作者官网载入，不在项目内复制整首文件。精选纯音乐明确显示为纯音乐，不伪造歌词。
- 添加本地音频：MP3、FLAC、WAV、OGG、M4A、Opus 等实际解码能力以浏览器为准。文件名为「歌手 - 曲名」时自动拆分显示。
- 播放列表、收藏、音频文件和导入歌词保存在当前浏览器 IndexedDB；音频文件不会上传。浏览器存储空间不足时保留本次访问的播放能力并提示。
- 支持播放/暂停、上一首/下一首、随机播放、点击进度条定位、音量、静音、系统媒体键以及曲目结束后的连续播放。重新载入时恢复当前曲目但不自动发声。
- LRC 文件可和同名音频一起添加，也可在选中歌曲后通过歌词区按钮导入。支持多时间戳、毫秒偏移与小数秒，当前行高亮并居中，点击歌词定位播放；纯文本歌词可滚动阅读。
- 没有本地歌词时，通过 LRCLIB 的 `/api/get` 按曲名、歌手和时长匹配；未匹配或网络不可用时显示导入歌词的入口。
- 搜索按钮使用 Internet Archive 高级搜索与元数据 API，仅收录项目元数据标明 Creative Commons 授权且有音频文件的结果。搜索按需发出；网络失败不影响已添加的本地音乐。结果里的来源链接用于查看具体授权。

## 沉浸学习与资源扩展（2026-10-18）

- 时钟与日期：桌面沿左侧留白放置，手机采用顶部紧凑布局。支持 12 / 24 小时制、三档字号、日期与秒数开关，以及左上 / 顶部居中 / 左下位置。秒数默认显示，以小字号跟随时分，沿用现有时钟每秒刷新与浏览器显示偏好保存。较窄窗口自动采用左侧紧凑布局，避免与播放器重叠。
- 专注计时：保留 25 / 45 / 60 分钟预设，并支持 1–180 分钟的整数自定义时长；可开始、暂停、继续、重置，暂停后可更换时长。按实际截止时间计算，切到博客或后台仍继续；同标签刷新后恢复。本轮完成仅温和提示，不打断音乐。记录本标签当天完成轮数。设置窗口也可直接暂停 / 继续计时。
- 双开关：右上角按「音乐、计时、退出」排列。首次采用新交互时两个面板默认收起，点击对应按钮展开，再点收起；后续记住各自开关状态。播放器默认在右侧，计时默认在左下；收起不产生散落的音乐或计时小入口。面板内的收起按钮同步更新顶部开关；播放和倒计时继续运行，收起后再展开保持原位置。
- 显示设置：移除「只看壁纸」及顶部独立设置入口。左侧时钟数字、计时数字和时长按钮打开「显示与专注」，原有时钟样式、自定义时长、光点偏好等仍可调整。计时卡片原「只看壁纸」位置改为「位置归位」。显示偏好升级为版本 2，迁移时保留时钟样式，清理旧壁纸视图状态。
- 壁纸增加 22 颗缓慢漂浮光点与低强度呼吸微光，随音乐播放状态显示，不分析音频频谱，兼容外站音频；可在专注设置中关闭。暂停背景、系统减少动态和后台标签页同样约束动画。
- 歌词窗口：面板入口打开大字阅读，逐行高亮、自动居中、点击跳转；支持导入 LRC / TXT、LRCLIB 手动关键词查找并选择版本、每曲 ±10 秒偏移（每次半秒）和一键归零。用户选定或导入的歌词仅存在当前浏览器。精选纯音乐明确说明没有人声歌词。
- 新增「电台」：接入 Radio Browser 公共目录，提供氛围、Lo-fi、古典、爵士四种风格，按需读取、缓存结果，并对目录镜像设置超时与回退。仅展示目录近期检查正常、HTTPS、常见浏览器音频格式的直连音频流，保留电台官网入口。直播显示「直播」、禁用进度拖动，不伪造时长和逐曲歌词。电台是公开直播，不代表其音乐可以自由再分发。
- GitHub 来源：[Radio Browser 服务源码和迁移说明](https://github.com/segler-alex/radiobrowser-api-rust)。该 GitHub 仓库已归档并迁移到 GitLab；本项目调用其公共目录，不安装已归档服务端。[当前接口文档](https://docs.radio-browser.info/)。
- 「音源说明」说明精选作者与 CC BY 4.0、在线电台、Internet Archive 搜索和本地导入。每个类型均有直接来源链接。
- 删除独立迷你播放条，原有樱花菜单内新增播放 / 暂停与下一首，原有音乐空间入口继续使用。樱花提示当前曲目并通过动画区分正在播放与已暂停。

新增维护文件：`src/components/MusicStudy.astro`、`src/scripts/music-study.ts`、`src/styles/music-study.css`、`src/scripts/music-radio.ts`。

本次显示优化另由 `src/scripts/music-display.ts` 管理双开关与显示偏好，`src/styles/music-display.css` 负责右上角控制、时钟布局和设置窗口；`src/scripts/music-drag.ts` 复用拖动逻辑，分别管理播放器与计时卡片的位置和归位。展开后的播放和曲库功能完整保留。

## 维护位置

- `src/pages/music.astro`：全屏壁纸页面与控制。
- `src/components/MusicPlayer.astro`：全站持久化播放器，以及音源说明和歌词窗口。
- `src/data/free-music.ts`：精选曲目、官方直链与署名信息。
- `src/styles/music.css`：全屏壁纸、磨砂播放器和响应式尺寸。
- `src/scripts/music-player.ts`：交互与播放状态。
- `src/scripts/music-drag.ts`：拖动、键盘移动、位置记忆与归位。
- `src/scripts/page-lifecycle.ts`：每次站内换页重新挂载场景与博客交互；普通界面监听器在换页前清理。
- `src/scripts/music-library.ts`：浏览器持久化。
- `src/scripts/music-lyrics.ts`：LRC 解析与在线歌词。
- `src/scripts/music-archive.ts`：开放音频检索。
- `src/components/SceneDock.astro` / `src/scripts/scene-dock.ts`：悬浮菜单入口。
